# ASX Shariah vs Conventional

Whether investing according to Shariah screens actually costs anything on the ASX, using S&P Dow Jones Indices' own Shariah index data.

Live: https://aneeq17.github.io/asx-shariah-vs-conventional/

Plain HTML/CSS/JS, no frameworks, no build step. Data and sources are cited on the page itself and in `shariah-scorecard-2026-06-30.json`.

To update the numbers later: edit the figures in `index.html` and `chart.js`, keep the JSON in sync, then push. GitHub Pages redeploys automatically within a minute or two.
